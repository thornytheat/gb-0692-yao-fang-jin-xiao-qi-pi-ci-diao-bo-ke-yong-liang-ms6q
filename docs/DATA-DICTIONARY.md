# 数据定义

FEFO仅分配到店后剩余有效期满足需求的库存；冻结量先扣，拆包需整包装，召回批不得调拨。盘点只报药品总数，盘亏按效期从近到远挂待落实扣减，落实后转已落实，盘盈不推断批号、不入可拨。

输入字段：record, kind, sku, lot, qty, frozen, pack, expiry, store, min_days, arrival, version, status。所有ID按字符串保留；空字符串、NULL、N/A、未知与“-”视为缺失，不能当作数值零。数值使用Decimal，输出为十进制字符串。重复业务键相同内容计重复，内容冲突隔离或按明确修订号裁决，不按文件顺序盲目覆盖。

每条证据有原始行号，隔离记录有原因码及原值。时间区间使用半开边界；日期定义在各模块规则内显式声明。输入表头可调序，不得缺列或重复；中文旧编码可上传。规则版本存入运行清单，重跑使用原始文件内容摘要与规则版本共同确定幂等键。复核使用revision乐观锁，陈旧提交返回409。

qty为库存件数或需求申请件数。frozen在stock行是冻结量，在demand行是门店已有可用量。库存先扣冻结，再按整包装向下取整；不能跨药品调拨。到期日当天不可用，剩余有效天数等于要求值时允许。缺口不自动改成零。截止日固定2026-11-18，便于复现。

## 盘点记录（kind=count）

盘点行只报药品总数：lot必须为空（含批号即隔离），qty为实盘总数，store为盘点仓位（与库存行store对应），arrival为盘点日期，status为pending（待落实）或confirmed（已落实）；frozen、pack、expiry、min_days忽略。同一盘点单号内容相同计重复、不重复扣减，内容冲突隔离，复盘须使用新单号。

对平口径：同一门店+药品按盘点日期先后链式结算，每次盘点与上一基准（首次为账面含失效批）比较得差异。盘亏按效期从近到远挂扣减，与FEFO消耗顺序一致，pending挂待落实、confirmed转已落实；盘亏超过可售（账面减冻结）部分记未分摊。盘盈先自远效期释放待落实扣减，余量挂盘盈，不推断未知批号、不进入可拨。召回与过期批按批号最大记录量从实盘中扣减（失效批扣减）后重算。恒等式：账面总数 − 待落实 − 已落实 − 未分摊 + 盘盈 = 实盘总数 − 失效批扣减。盘后可用 = （账面 − 冻结 − 扣减）按整包装向下取整，合计不超过有效实盘，后续调拨以此为准，不会超发。被覆盖的盘点单保留在盘点单记录与证据CSV中。
